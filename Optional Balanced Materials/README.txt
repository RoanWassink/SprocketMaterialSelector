Optional Balanced Materials — Material Selector 0.4.8

Eleven optional passive gameplay presets, balanced against vanilla RHA. Preset
values and IDs are unchanged. These are fictionalized gameplay choices, not
measured engineering data; ElastomerNERA here is passive, not an active NERA recipe.

Close Sprocket. Copy the JSON files to Sprocket_Data/StreamingAssets/Technology.
Back up matching files and preserve your edits; never overwrite vanilla RHA or
sheet metal. Material availability follows each native Technology date. Editing
existing IDs changes vehicles already saved with those materials. Keep save backups.
